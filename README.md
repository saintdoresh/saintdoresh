<details>
<summary><b>How Spendprofile works under the hood</b></summary>
<br>

Fourteen Nigerian banks, fourteen statement formats. Password-protected PDFs, statements that run past sixty pages, layouts that change without warning. I took an early engine draft from contract engineers, scaled it into a pipeline that turns every one of those formats into a single transaction model, and built the backend and UI that got the product to MVP. The bank-data library is published on npm and PyPI.

I now lead product design, brand and the web experience, with a technical co-founder running engineering.

</details>

<details>
<summary><b>How Urcrib is built</b></summary>
<br>

Three surfaces: a customer app, a vendor portal and an admin console. Every measurement in a plan records how it was taken and how sure it is (tiles counted, wall paced, tape used), so the plan shows its own margin of error instead of pretending to be exact.

I wrote the engineering standards and data invariants first, then built features with AI coding agents working from those specs. One designer-engineer, three products, one set of rules.

</details>
